## 版本说明（v1.1.0）

```
本次更新：编解码短板补齐 + 全新「加解密」分类（AES / RSA）。

新增工具
- AES 加解密：CBC / GCM 模式，密钥一键生成（128/192/256 位），IV 分栏展示，
  GCM 篡改密文自动识别
- RSA 加解密：密钥对生成、加密解密、签名验签，支持私钥提取公钥
- 图片/文件转 Base64：拖入即转 Base64 / Data URL，自动识别格式、图片预览、
  复制图片、另存为
- Base32 编解码（RFC 4648）与字符编码转换（GBK / UTF-8 / UTF-16，乱码复原）

功能增强
- URL 编码新增「智能模式」；解码遇非法 % 序列不再整体失败
- Base64 支持 Base64URL 输出与空白容错；JSON 工具新增转义 / 去转义
- 时间戳匹配放宽至 8–13 位；复制内容统一去首尾空白
- 颜色工具新增「屏幕取色」

修复
- 9 位时间戳识别不对、URL「中文20%英文」解码失败、UUID 复制带隐形换行
- JSON 大文件折叠展开错乱、窗口较矮时区块叠压
```

## 插件应用介绍

```
DevTools Kit 是面向开发者的 uTools 一站式开发工具箱，聚合 18 个高频小工具，
覆盖编解码、加解密、时间日期、文本生成、设计辅助五类场景。

✨ 核心特性

• 输入即转换：所见即所得，结果一键复制，Ctrl+Enter 快捷送入主结果
• 智能匹配：直接粘贴时间戳、URL、JSON、UUID、颜色值，
  uTools 自动识别并进入对应工具
• 搜索直达：支持「时间戳」「base64」「AES」「RSA」「农历」「二维码」等中文与英文关键词
• 加解密：AES-CBC/GCM 对称加密、RSA 密钥对与签名验签，纯本机运算，密钥不落盘
• 乱码复原：GBK / UTF-8 / UTF-16 字节级互转，经典乱码一键修复
• 暗色模式：跟随系统 / 亮色 / 暗色三种模式
• 历史记录：仅保存在本机（uTools db），随时可清空

🔒 隐私承诺：全部计算在本地完成，插件不发起任何网络请求，
不上传任何数据，无遥测统计。

🧰 工具清单
编解码：时间戳转换 · Base64 · Base32 · 图片/文件转 Base64 · URL 编解码 ·
        JSON 格式化 · 进制转换 · 哈希计算（MD5/SHA-1/SHA-256/SHA-512）·
        Unicode 转中文 · 字符编码转换（GBK/UTF-8/UTF-16）
加解密：AES 加解密（CBC/GCM）· RSA 加解密（密钥对/加密/签名验签）
时间日期：日期换算（农历 / 星期 / 年内序数 / 日期差）
文本生成：UUID v4 批量生成 · 命名风格转换（camel/snake/kebab 等）·
          文本统计 · 二维码生成
设计辅助：颜色格式转换（HEX / RGB / HSL 互转预览）· 屏幕取色

开源地址：https://github.com/HelloThreeLiu/devtools-kit
```
