## 插件应用介绍

```
DevTools Kit 是面向开发者的 uTools 一站式开发工具箱，聚合 13 个高频小工具，
覆盖编解码、时间日期、文本生成、设计辅助四类场景。

✨ 核心特性

• 输入即转换：所见即所得，结果一键复制，Ctrl+Enter 快捷送入主结果
• 智能匹配：直接粘贴 10/13 位时间戳、URL、JSON、UUID、颜色值，
  uTools 自动识别并进入对应工具
• 搜索直达：支持「时间戳」「base64」「json」「农历」「二维码」等中文与英文关键词
• 暗色模式：跟随系统 / 亮色 / 暗色三种模式
• 历史记录：仅保存在本机（uTools db），随时可清空

🔒 隐私承诺：全部计算在本地完成，插件不发起任何网络请求，
不上传任何数据，无遥测统计。

🧰 工具清单
编解码：时间戳转换 · Base64 · URL 编解码 · JSON 格式化 · 进制转换 ·
        哈希计算（MD5/SHA-1/SHA-256/SHA-512）· Unicode 转中文
时间日期：日期换算（农历 / 星期 / 年内序数 / 日期差）
文本生成：UUID v4 批量生成 · 命名风格转换（camel/snake/kebab 等）·
          文本统计 · 二维码生成
设计辅助：颜色格式转换（HEX / RGB / HSL 互转预览）

开源地址：https://github.com/HelloThreeLiu/devtools-kit
```
