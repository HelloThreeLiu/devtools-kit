## 一、高优先级修复

### H1. JSON 折叠超长内容崩溃 → 已修复

**修复**（`src/tools/json/index.vue`）：折叠区间改为基于「实际渲染行」计算——新增 `shown` computed（截断后的行数组），`folds = computeFolds(shown)`，`renderRows` 复用同一 `shown`。闭合行在截断边界之外的节点不再出现在 `folds` 中 → 折叠按钮不渲染 → 不可能触发 `undefined.trim()`。正常范围（<5000 行）的折叠功能不受影响。

**验证**：复现脚本两场景通过（6000 行 JSON 无崩溃 + 11 行 JSON 折叠区间 `{0→10, 1→4, 5→9}` 正确）。

### H2. JSON 大输入防抖死代码 → 已修复

**修复**（`src/tools/json/index.vue`）：`result` computed 改为消费 `effectiveInput`（>100KB 时 200ms 防抖后的值），lint + format + 高亮整条渲染链均走防抖，与技术设计 §12 一致。`excerpt`/折叠重置/历史记录本就基于 `effectiveInput`，现在全链路一致。同时补 `onUnmounted(() => clearTimeout(timer))` 清理防抖定时器。

### H3. 二维码「导出 PNG」→ 已实现

**修复**（`src/tools/qrcode/index.vue`）：新增「导出 PNG」按钮，经 `<a download>` 触发浏览器/Electron 下载能力，文件名 `qrcode-<时间戳>.png`，成功后轻提示。与「复制图片」并排。

### H4. 颜色「拾色器」→ 已实现

**修复**（`src/tools/color/index.vue`）：预览色块改为 `<input type="color">`（点击弹出系统颜色选择器），选中后回填输入框触发全格式换算。样式上清除原生 padding/border 使其与设计令牌一致（`::-webkit-color-swatch` 处理）。`pickerHex` 只取 `#rrggbb` 部分回显（type=color 不支持 alpha），alpha 信息仍由「透明度」标签与输出行呈现。移除原 `swatchStyle` 渐变模拟逻辑。

### H5. Ctrl+Enter 复制主结果 12/13 缺失 → 已统一实现

**修复**：新增组合式函数 `src/utils/mainResult.js`：

- `useMainResult(fn)`：工具组件 setup 时注册主结果 getter（`fn()` 返回 `{ value, label }` 或 null），随组件卸载自动注销；
- `useMainResultKey()`：ToolShell 挂载期间在 **document 级**监听 Ctrl/Cmd+Enter（同时修复了 timestamp 原实现 footer 在 `@keydown` 作用域外的提示矛盾问题），随 ToolShell 卸载移除。

13 个工具接入情况：

| 工具 | 主结果 |
| --- | --- |
| timestamp | 时间戳输入 → 本地时间；日期输入 → 秒级时间戳（沿用原方向逻辑） |
| base64 / url-codec / unicode / json | 转换输出 / 格式化结果（json 复制完整内容不受截断影响） |
| radix | 十进制结果 |
| uuid | 全部 UUID（换行分隔） |
| hash | 四种摘要全文（`MD5: …` 多行） |
| date-calc | 「日期 + 星期 · 农历」摘要 |
| case-convert | camelCase |
| text-stat | 一句话统计摘要 |
| color | HEX |
| qrcode | *不适用*（主结果为图片，复制走「复制图片」按钮）——文档化例外 |

timestamp 原组件内 `onKeydown` 与 `@keydown` 绑定已移除，避免双重处理。

## 二、中优先级修复

### M1. uuid 格式切换重新生成 → 已修复

**修复**（`src/tools/uuid/index.vue`）：拆分「原始批次」与「展示列表」——`rawList`（ref，标准小写形态）保存生成的 UUID；`list` 改为 computed，对同一批做 `formatUuid` 映射。`setFormat` 只切换格式不再调用 `regenerate()`。「重新生成」/数量变更仍产生新批次。顺带 `:key` 改为索引。

### M2. 历史防抖定时器泄漏 → 已统一修复

**修复**：新增组合式函数 `src/utils/histRecorder.js`：

```
useHistRecorder(toolId, source, toOutput)
```

输入停顿 1s 后调用 `toOutput(v)`（支持同步值与 Promise），返回真值即 `recordHistory(toolId, v, output)`，空值跳过；抛错（含异步 reject）静默；内置 seq 守卫丢弃过期异步结果；**onUnmounted 时清理定时器并停止 watch**。12 个有输入的工具全部由旧的手写 `histTimer` watch 迁移至该函数（uuid 无输入驱动，不适用）。

### M3. date-calc 打开即写历史 → 已修复

**修复**（`src/tools/date-calc/index.vue`）：引入 `autoFilled` 标记——`fillToday()` 填充时记录该字符串；recorder 回调对 `v === autoFilled` 的输入跳过记录；用户一旦输入其他内容（watch 检测）即清除标记，后续正常记录。历史回填/手动输入不受影响。

### M4. 匹配指令 payload 残留 → 已修复

**修复**（`src/router.js`）：`handlePluginEnter` 中，若目标工具与当前路由相同且携带 payload，改为直接 `replay(id, consumeEnterPayload())` 立即回填给已挂载的组件（不再依赖 onMounted 消费），payload 不会残留污染下一次进入。

### M5. text-stat 复制 + 截断 → 已修复

**修复**（`src/tools/text-stat/index.vue`）：统计面板新增「复制」按钮与 Ctrl+Enter 主结果（`N 字符 · N 词 · N 行 · UTF-8 N 字节`）；历史记录移除 `v.slice(0, 80)` 私自截断，交由 db.js 统一上限（5000 字符）处理。

### M6. 二维码 1000 字符预校验 → 已实现

**修复**（`src/tools/qrcode/index.vue`）：输入超过 1000 字符时即时行内红字提示（含当前长度），不再送入 qrcode 库；输入框上方新增实时 `当前长度 / 1000` 计数标签（超限变红）。
