DESIGN NOTES · 设计说明（对应 PRD 4.3.2）
  • 自动识别：命中 Base64 字符集且长度 %4===0 时默认解码，可手动锁定模式（功能要求）
  • UTF-8 安全：中文/Emoji 编解码往返正确（验收：你好 → 5L2g5aW9…）
  • URL-Safe 容错：-/_ 自动归一化，缺省 padding 自动补齐（验收标准）
  • 非法字符（如 ab!c）行内报错「包含非法字符」，不崩溃（验收标准）
  • 底部实时统计字节数，辅助判断编码体积
