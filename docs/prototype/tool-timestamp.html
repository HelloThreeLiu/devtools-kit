DESIGN NOTES · 设计说明（对应 PRD 4.3.1）
  • 输入即转换：输入变化 ≤ 100ms 出结果，无「转换」按钮（PRD 4.2-1）
  • 每个结果独立复制：⧉；Ctrl+Enter 复制主结果（PRD 4.2-2）
  • 位数识别规则：10 位=秒、13 位=毫秒、16 位提示不支持；其余报错不输出（验收标准）
  • 相对时间每 30s 随时钟刷新；时区在实时条注明（验收标准）
  • 呼起即聚焦输入框、Ctrl+V 粘贴即用（PRD 4.2-3）
