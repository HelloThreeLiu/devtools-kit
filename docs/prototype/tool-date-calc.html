DESIGN NOTES · 设计说明（对应 PRD 4.4.1）
  • 农历卡片当前为演示数据：正式版接入 1900–2100 查表算法，单测对拍 20 个抽查日期（验收标准）
  • 星期 / 年内序数 / ISO 周 / 日期差为真实计算，可直接验收
  • 日期差取 UTC 12:00 计算，规避夏令时 ±1 天误差（§11.2）
  • 「今天」一键填入当前日期（功能要求）
  • 非法日期（如 2025-02-30）行内报错，不做自动进位（PRD 4.2-4）
